# Discord Bot

## 專案結構

```text
commands/
  <指令名稱>/index.py    # 每個資料夾只註冊一個斜線指令
  shared/                # 跨指令共用的純工具函式
  出貨/stock_service.py   # 同一功能群組的服務層
config.py                # 所有環境變數與頻道設定
database.py              # SQLite 資料存取與資料表初始化
fix_db.py                # 舊資料庫的修復工具（一般情況不需要執行）
main.py                  # 機器人啟動、指令載入與持久化視圖註冊
```

## 新增指令

1. 建立 `commands/指令名稱/__init__.py` 與 `commands/指令名稱/index.py`。
2. 在 `index.py` 內只註冊一個 `@app_commands.command`。
3. 將可重用邏輯放入 `commands/shared/` 或該功能資料夾的服務模組；不要從另一個指令的 `index.py` 匯入。
4. 重啟機器人，`main.py` 會自動載入新資料夾的 `index.py`。

目前已整理的入口指令為：`say`、`mute`、`取消訂單`、`訂單工具`、`出貨`、`庫存`、`查詢消費`、`調整消費`。`/say` 可選擇發送一般訊息或 Embed。

## 多伺服器設定

同一個 Bot Token 可以加入多個伺服器，不需要啟動多份程式。將機器人邀請到伺服器後，由該伺服器管理員執行：

```text
/設定伺服器
```

可分別設定訂單接單頻道、結單日誌頻道、100m/200m 庫存頻道與出貨日誌頻道。設定會依 `guild_id` 儲存，各伺服器的訂單、消費與出貨紀錄互相隔離。

庫存商品不是固定的 100m/200m。每個伺服器可以用自己的商品名稱建立變數：

```text
/setup product_name:台服月卡 channel_id:123456789012345678
/setup product_name:美服帳號 channel_id:234567890123456789
```

輸入既有商品名稱可以修改頻道；輸入 `clear` 可以刪除商品：

```text
/setup product_name:台服月卡 channel_id:clear
```

設定完成後，`/出貨` 與 `/庫存` 會讓管理員選擇該伺服器自己的商品名稱與數量。不同伺服器可以使用完全不同的商品名稱與庫存頻道。

訂單付款帳號也按伺服器分開設定：

```text
/設定付款 payment_method:銀行轉帳 account_info:銀行代碼與帳號
/設定付款 payment_method:PayPal account_info:PayPal 帳號資訊
```

付款方式名稱可以完全自訂；輸入既有名稱會更新內容。刪除某種付款方式：

```text
/設定付款 payment_method:PayPal account_info:clear
```

訂單免責聲明也能由每個伺服器管理員自行設定。使用 `/設定訂單免責聲明` 開啟編輯表單並送出；只會影響目前伺服器。要恢復系統預設文案，請在表單內容輸入 `重設預設`。

## 環境變數

`.env` 只需要設定 `DISCORD_TOKEN`。舊版的頻道環境變數仍可保留，但新的多伺服器功能會以 `/設定伺服器` 的設定為準。

## 訂單流程與顧客評價

管理員或具備「管理訊息」權限的客服執行 `/訂單工具` 後，先填妥訂單內容。機器人會在目前頻道標記指定客人並顯示免責聲明；客人按「我已閱讀並確認訂單內容」後，該訊息才會顯示完整訂單與付款方式。打手數量為 0 的商品訂單不會派發搶單；付款確認後由客服按「完成結單」。其他需要打手的訂單會在確認付款後送至搶單頻道。

訂單編號為全資料庫不重複的 8 碼編號。訂單 Embed 會顯示老闆、商品、開單時間與結單時間。

管理員或具備「管理訊息」權限的客服可以選擇付款方式及確認收款。結單後，評價按鈕會留在訂單所在的客服頻道；私訊只會發送訂單內容，不包含評價按鈕。

在 `/設定伺服器` 設定「顧客評價發布頻道」後，老闆可在訂單所在頻道按「留下評價」。填寫評論與 1～5 顆星後，機器人會將包含老闆名稱、頭像、商品名稱、評論、星數與時間的 Embed 發送到評價頻道。

每張訂單只能成功提交一次評價；重複點擊或重複送出會被拒絕。

若訂單完成後超過 24 小時仍未評價，系統會自動在評價頻道發送 5 星評價，評論為：
`超過 24 小時未評價，系統自動給予五星`
